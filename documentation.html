Installation

Quick Start Guide

Getting CFCMonitor up and running is straightforward. Follow these steps for a smooth installation:

  1. Download the Application: Get the latest version of CFCMonitor from the official source
  2. Launch the Executable: Run CFCMonitor_V(#).exe to start the application
  3. Locate Game Log: When prompted, navigate to your Star Citizen game log file:
    • Default location: C:\Program Files\Roberts Space Industries\StarCitizen\LIVE\Game.log
    • If not found, check alternative locations or enable hidden files in Windows Explorer
  4. Authentication: The application will verify your CFC organization membership automatically
  5. Configuration: Access settings through File → Settings to customize your experience

System Requirements

  • Windows 10 or Windows 11
  • Star Citizen installed and configured
  • Internet connection for database synchronization
  • Minimum 4GB RAM (8GB+ recommended)

Usage Guide

Application Interface

CFCMonitor features a clean, intuitive interface with several key sections:

📊 Player Stats Tab

View your lifetime and session statistics, K/D ratios, achievement progress, and leaderboard rankings.

📰 Feed Tab

Real-time activity monitor showing kills, deaths, achievements, and system messages with timestamps.

⚙️ Settings

Customize themes, notifications, console appearance, and application behavior preferences.

🔗 Links Menu

Quick access to Star Citizen resources, community tools, and trading platforms.

Key Features

  • Automatic Log Monitoring: Continuously watches your Star Citizen game log for events
  • PvP/PvE Classification: Automatically categorizes combat events based on opponent types
  • Achievement Tracking: Real-time achievement unlocks with detailed progress tracking
  • Theme Customization: Multiple themes including Star Citizen-themed options
  • System Tray Support: Run in background while maintaining full functionality
  • Discord Notifications: Automatic webhook notifications for significant events

Basic Workflow

  1. Start CFCMonitor_V(#).exe before or after launching Star Citizen
  2. The application automatically begins monitoring your game log
  3. View real-time events in the Feed tab
  4. Check your statistics and achievements in the Player Stats tab
  5. Customize settings and themes as desired
  6. Minimize to system tray for background operation

Troubleshooting Quick Tips

  • Events Not Detected: Verify game log path and reload program.
  • Database Errors: Check internet connection and firewall settings
  • Application Won't Start: Check for multiple instances and corrupted config files
  • Performance Issues: Disable debug logging tab and consider running from SSD
  • Statistics Not Updating: Allow 2-5 minutes for database synchronization
