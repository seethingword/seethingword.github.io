Welcome to the Moderator Commands page!

Stream Control Commands

!status (message) Changes the title for the stream.
!game (game) Changes the game category for the stream.

Command Control Commands

!command add (command) (permlevel) (response) Creates a new command with a set permission level & response.
!command edit (command) (permlevel) and/or (response) Edits a command with a new permission level and/or response.
!command remove (command) Completely removes a command.
!enable (command) (true/false) Enables or disables a command.
!command cooldown (command) (minutes) Sets a cooldown on a command in minutes.
!command usercooldown (command) (minutes) Sets a cooldown on a command for normal users in minutes.

Quote Commands

!quote add (text) Creates a quote with the given text.
!quote edit (id) (text) Edits the quote of the id given with the new given text.
!quote remove (id) Removes a quote entirely.
!quote Gives a random saved quote as a response.
!quote (id) Gives a specific saved quote as a response depending on the id given.

Currency Commands

!points add (name) (amount) Gives the specified amount of points to the specified user.
!points remove (name) (amount) Removes the specified amount of points from the specified user.
!points add +active (amount) Gives the specified amount of points to all active users in chat.
!points add +viewers (amount) Gives the specified amount of points to all viewers in chat (active and inactive).
!transfer (fromUser) (toUser) Transfers all points from a user to another user.

Song Request Commands

!songblacklist add (url/token) Adds a YouTube video to the blacklist using url or token.
!songblacklist remove (url/token) Removes a YouTube video from the blacklist using url or token.
!skip Allows an immediate skip of the current song.
!volume (0-100) Allows user to set a new song volume between 0 & 100.
