General Commands

!pointsDisplays the amount of points the user has.
!topDisplays a list of top users based on points.
!tophoursDisplays a list of top users based on hours.
!give (name) (amount)Give points from a user to another user.
!heistAllows viewers to start a heist!
!gamble (amount)Allows viewers to gamble using their points.
!8ballAllows viewers to ask questions to eight ball.
!slotsAllows viewers to gamble points on the slot machine.
!duel (name)Allows viewers to duel with each other for points.
!acceptAllows viewer to accept a duel.
!denyAllows viewer to deny a duel.
!cancelAllows viewer to cancel the initiated duel.

Song Request Commands

!songrequest (url/token) or !sr (url/token) Request a song using a YouTube video link or token.
*Full video link or anything after "watch?v="*
!veto Vote to veto a song request. (Costs 150 points to vote)
!wrongsong Cancel last song request if you used the wrong link/token.
