General Commands


!points Displays the amount of points the user has.

!top Displays a list of Top users based on points.

!tophours Displays a list of Top users based on hours.

!give (name) (amount) Give points from a user to another user.

!heist Allows viewers to start a heist!

!gamble (amount) Allows viewers to gamble using their points.

!8ball Allows viewers to ask questions to eight ball.

!slots Allows viewers to gamble points on the slot machine.

!duel (name) Allows viewers to duel with each other for points.

!accept Allows viewer to accept a duel.

!deny Allows viewer to deny a duel.

!cancel Allows viewer to cancel the initiated duel.



Song Request Commands


!songrequest (url/token) or !sr (url/token) Allows viewer to request a song using a YouTube video link or YouTube Video Link Token. *Full video link or anything after "watch?v="*

!veto Allows viewer to vote to veto a song request. (Costs 150 points to vote)

!wrongsong Allows viewer to cancel last song request placed if used the wrong link/token.
