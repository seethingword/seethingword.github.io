Common Issues & Solutions

Application Issues

❌ CFCMonitor Won't Start

  • Check if another instance is already running (check system tray)
  • Run as Administrator if you encounter permission errors
  • Verify Windows version compatibility (Windows 10/11 required)
  • Check for corrupted configuration files in the application directory
  • Restart your computer to clear any locked processes

🎯 Events Not Being Detected

  • Verify the game log path is correct: C:\Program Files\Roberts Space Industries\StarCitizen\LIVE\Game.log
  • Make sure Star Citizen is actually running and generating logs
  • Check if the log file has recent timestamps
  • Reload the program using File → Reload Program

🌐 Database Connection Problems

  • Check your internet connection stability
  • Verify firewall isn't blocking CFCMonitor
  • Try disabling VPN temporarily if using one
  • Check if your antivirus is interfering with network connections
  • Wait for server maintenance periods to complete

📊 Statistics Not Updating

  • Allow 2-5 minutes for database synchronization
  • Check if you're authenticated as a CFC member
  • Verify your Player Handle is correctly being detected
  • Try refreshing the statistics panel
  • Ensure events are being detected in the main log panel

Performance Issues

🐌 Slow Performance or High CPU Usage

  • Disable the debug logging tab if not needed
  • Run CFCMonitor from an SSD instead of HDD
  • Close other resource-intensive applications
  • Consider disabling window overlay if performance is critical

💾 High Memory Usage

  • Restart CFCMonitor periodically during long sessions
  • Clear log history if it becomes very large
  • Disable unnecessary features like Twitch integration if not used
  • Check for memory leaks by monitoring usage over time

Detailed Troubleshooting

Configuration Issues

⚙️ Settings Not Saving

  • Run CFCMonitor as Administrator
  • Check if the application directory is write-protected
  • Verify disk space is available
  • Look for config file corruption in application folder

🎨 Theme or Display Issues

  • Try switching to default theme in settings
  • Check Windows display scaling settings
  • Update graphics drivers
  • Verify monitor resolution compatibility

Achievement System Issues

🏆 Achievements Not Unlocking

  • Review achievement criteria in the Achievement Guide
  • Check if events are being properly categorized (PvP vs PvE)
  • Verify your statistics are updating correctly
  • Some achievements may have hidden progress requirements
  • Wait for database synchronization (achievements may unlock with delay)

Self-Help Resources

Before reaching out for help, consider these resources:

  • Application Logs: Check the debug tab for error messages
  • Windows Event Viewer: Look for application-specific errors
  • System Requirements: Verify your system meets minimum requirements
  • Recent Changes: Consider if recent system changes might be related
  • Clean Installation: Sometimes a fresh install resolves persistent issues
  • Files related to the program locations:
  • - Your .exe location
  • - Your configuration files location (C:\Users\[USERNAME]\AppData\Roaming\StarCitizenLogMonitor)

System Information Checklist

When reporting issues, having this information ready helps us assist you faster:

Basic Information

  • CFCMonitor version number
  • Windows version (Windows 10/11)
  • Star Citizen version and game mode
  • When the issue started occurring

Technical Details

  • Error messages (exact text)
  • Steps to reproduce the issue
  • What you expected to happen
  • Any recent changes to your system

Application State

  • Current settings configuration
  • Any enabled integrations (Discord, Twitch)
  • Recent log entries from debug tab
  • Performance impact observed
