🚀 Quick Start Configuration

▼

First-Time Setup Wizard

▼

When you first launch CFCMonitor, follow these essential setup steps:

  1. Game Log Location: Point CFCMonitor to your Star Citizen game log file
  2. Player Verification: Authenticate your CFC organization membership
  3. Basic Settings: Configure your preferred theme and notification settings
  4. Test Connectivity: Verify database connection and data synchronization
Default Game Log Path:
C:\Program Files\Roberts Space Industries\StarCitizen\LIVE\Game.log
⚠️ Important: Make sure Star Citizen has been run at least once (And gotten to main menu) initial setup for best results.

Configuration File Location

▼

CFCMonitor stores all configuration in a JSON file located at:

Windows:
%APPDATA%\StarCitizenLogMonitor\config.json

macOS:
~/Library/Application Support/StarCitizenLogMonitor/config.json

Linux:
~/.config/StarCitizenLogMonitor/config.json
💡 Tip: You can backup this file to save your settings, or share configurations between installations.

⚙️ Core Settings

▼

Game Log Monitoring

▼

Game Log Path Configuration

The most critical setting in CFCMonitor is the path to your Star Citizen game log file.

Setting: GAME_LOG_PATH
Default: "" (empty - must be configured)
Purpose: Tells CFCMonitor where to find your Star Citizen game logs

Common Locations:

  • Live Branch: C:\Program Files\Roberts Space Industries\StarCitizen\LIVE\Game.log
  • PTU Branch: C:\Program Files\Roberts Space Industries\StarCitizen\PTU\Game.log
  • EPTU Branch: C:\Program Files\Roberts Space Industries\StarCitizen\EPTU\Game.log
  • Custom Install: [Your Custom Path]\StarCitizen\[BRANCH]\Game.log

Current Monitored Log

Setting: CURRENT_MONITORED_LOG
Purpose: Tracks which specific log file is currently being monitored

Game Version Support

Setting: GAME_VERSIONS
Default: [] (array)
Purpose: Stores information about supported Star Citizen versions

User Identification & Privacy

▼

Client User ID

Setting: CLIENT_USER_ID
Default: Auto-generated UUID
Purpose: Unique identifier for your CFCMonitor installation

This unique ID is automatically generated when you first run CFCMonitor. DO NOT EDIT THIS LINE!!!

🔒 Privacy Note: This ID is completely anonymous and cannot be used to identify you personally. Only your in-game handle and statistics are associated with it.

Close Button Behavior

Close Button Options:

Debug Features

Default: false
Purpose: Shows additional debugging information and logs

📺 Real-time Overlay Configuration

▼

Enable Overlay

▼
Setting: ENABLE_OVERLAY
Default: false
Purpose: Shows real-time statistics and events over your game

The overlay displays important information while you play Star Citizen, including:

  • Kill/death notifications
  • Achievement unlocks
  • Session statistics
  • Current K/D ratio
⚠️ Performance Note: The overlay may impact game performance on lower-end systems. Test with your setup and disable if needed.

Overlay Appearance

▼

Text Color

Setting: OVERLAY_TEXT_COLOR
Default: "#00FF00" (green)
Format: Hex color code
Purpose: Color of overlay text

Font Settings

Font Family: OVERLAY_FONT_FAMILY (Default: "Arial")
Font Size: OVERLAY_FONT_SIZE (Default: 24)
Bold: OVERLAY_FONT_STYLE_BOLD (Default: true)
Italic: OVERLAY_FONT_STYLE_ITALIC (Default: false)
Underline: OVERLAY_FONT_STYLE_UNDERLINE (Default: false)

Recommended Font Families:

  • Arial: Clean, highly readable
  • Helvetica: Modern, professional look
  • Consolas: Monospace, good for statistics
  • Impact: Bold, high visibility

Overlay Position & Timing

▼

Position

Setting: OVERLAY_POSITION
Default: "top-left"
Options: "top-left", "top-right", "bottom-left", "bottom-right", "top-center", "bottom-center"

Display Duration

Setting: OVERLAY_DISPLAY_DURATION_MS
Default: 3000 (3 seconds)
Purpose: How long notifications stay visible (in milliseconds)

Position Recommendations:

  • top-left: Doesn't interfere with HUD elements
  • top-right: Good for monitoring while flying
  • bottom-left: Away from chat area
  • bottom-right: Near minimap, good for quick reference
  • bottom-center: High visibility but may obstruct gameplay
  • top-center: Good for monitoring while flying

Notification Sounds Setup

▼

Enable Sound Notifications

Setting: ENABLE_NOTIFICATION_SOUNDS
Default: true
Purpose: Master switch for all audio notifications

Volume Control

Setting: NOTIFICATION_SOUND_VOLUME
Default: 50
Range: 0-100
Purpose: Controls volume of all notification sounds

Custom Sound Files

▼

CFCMonitor supports custom sound files for different event types:

Setting: NOTIFICATION_SOUNDS
Structure: Object with sound file paths
Supported Events:
  • "kill" - PvP kills
  • "death" - PvP deaths
  • "achievement" - Achievement unlocks
  • "pve_kill" - PvE kills
  • "pve_death" - PvE deaths
  • "crash" - Game crashes
  • "suicide" - Self-inflicted deaths
  • "suffocation" - Environmental deaths

Sound File Requirements

  • Supported Formats: WAV, MP3, OGG
  • Recommended Length: 1-3 seconds
  • File Size: Under 1MB for best performance
  • Quality: 44.1kHz, 16-bit recommended
💡 Tips for Custom Sounds:
  • Use short, distinctive sounds that won't interfere with game audio
  • Test volume levels during gameplay
  • Consider different tones for different event types
  • Keep files in a dedicated folder for easy management

📹 Streaming & Integration

▼

Twitch Bot Integration

▼

Enable Twitch Bot

Setting: ENABLE_TWITCH_BOT
Default: false
Purpose: Enables automatic Twitch chat integration

Twitch Configuration

Channel: TWITCH_CHANNEL - Your Twitch channel name
Bot Username: TWITCH_BOT_USERNAME - Bot account name
OAuth Token: TWITCH_OAUTH_TOKEN - Authentication token
Auto Connect: AUTO_CONNECT_TWITCH - Connect on startup

Setting Up Twitch Integration

  1. Create or use an existing Twitch account for your bot
  2. Generate an OAuth token at antiscuff.com/oauth/
  3. Enter your channel name (without the #)
  4. Test the connection before going live
⚠️ Security: Keep your OAuth token private. Never share it publicly or in screenshots.

Text Labels for OBS

▼

Enable Text Labels

Setting: ENABLE_TEXT_LABELS
Default: false
Purpose: Creates text files for OBS/streaming software to read

Output Path

Setting: TEXT_LABELS_OUTPUT_PATH
Default: "" (empty)
Purpose: Folder where text files are created

Available Labels

Setting: ENABLED_LABELS
Purpose: Controls which statistics are written to text files for OBS/streaming software

All Available Label Options:

📊 Session Statistics

  • "total_kills_session" - Total PvP kills in current session
  • "total_pve_kills_session" - PvE kills in current session only

🎯 Lifetime Statistics

  • "pvp_kills_total" - Total lifetime PvP kills
  • "pve_kills_total" - Total lifetime PvE kills
  • "pvp_deaths_total" - Total lifetime PvP deaths

👤 Player Information

  • "last_player_killed" - Name of the last player you killed
  • "player_who_killed_user_last" - Name of the last player who killed you

📍 Location Data

  • "last_kill_location" - Location where your last kill occurred
  • "last_death_location" - Location where your last death occurred

🔫 Weapon Information

  • "last_weapon_used_to_kill_player" - Last weapon you used to kill someone
  • "last_weapon_used_to_kill_user" - Last weapon used to kill you

⏰ Timing Data

  • "time_since_last_pvp_death" - Time elapsed since your last PvP death
  • "time_since_last_pvp_kill" - Time elapsed since your last PvP kill
💡 Usage Tips:
  • Enable only what you need - Reduces file I/O and improves performance
  • Session stats - Great for stream overlays showing current session progress
  • Lifetime stats - Perfect for persistent achievement displays
  • Recent events - Ideal for showing latest kills, deaths, and weapons used
  • Timing data - Useful for streak tracking and performance analysis

Setting Up OBS Text Sources

  1. Choose an output folder (e.g., C:\Streaming\CFCLabels\)
  2. Enable the labels you want to display
  3. In OBS, add Text (GDI+) sources
  4. Check "Read from file" and browse to your label files
  5. Style and position the text elements

🔧 Troubleshooting Configuration Issues

▼

Configuration File Problems

▼

Common Issues

Problem: Settings not saving or loading
Solution:
  1. Check if CFCMonitor has write permissions to the config directory
  2. Ensure no other instances are running
  3. Try running as administrator
  4. Verify config.json is not set to read-only

Problem: Corrupted configuration file
Solution:
  1. Close CFCMonitor completely
  2. Navigate to config directory
  3. Rename config.json to config_backup.json
  4. Restart CFCMonitor (will create new config with defaults)
  5. Reconfigure your settings

Problem: Settings reset after each restart
Solution:
  1. Check antivirus software isn't blocking file writes
  2. Verify Windows User Account Control settings
  3. Move config directory to a different location
  4. Check available disk space

Overlay Not Working

▼
Check These Settings:
  1. Verify ENABLE_OVERLAY is set to true
  2. Ensure Star Citizen is running in Fullscreen or Windowed mode (not Borderless)
  3. Check if overlay position is visible on your monitor setup
  4. Try different overlay positions to test functionality
  5. Verify overlay color isn't blending with game background
Advanced Solutions:
  1. Run CFCMonitor as administrator
  2. Disable fullscreen optimizations for Star Citizen
  3. Check for conflicts with other overlay software
  4. Update graphics drivers
  5. Try running in compatibility mode

Audio Notifications Not Playing

▼
Basic Checks:
  1. Verify ENABLE_NOTIFICATION_SOUNDS is true
  2. Check NOTIFICATION_SOUND_VOLUME is above 0
  3. Ensure sound files exist at specified paths
  4. Test with default Windows sounds first
  5. Check system audio mixer for CFCMonitor volume
File Path Issues:
  1. Use absolute file paths (e.g., C:\Sounds\kill.wav)
  2. Avoid spaces in file names or use quotes
  3. Ensure sound files are in supported formats (WAV, MP3, OGG)
  4. Check file permissions and accessibility

Text Labels Not Updating

▼
Configuration Checks:
  1. Verify ENABLE_TEXT_LABELS is true
  2. Check TEXT_LABELS_OUTPUT_PATH is set and valid
  3. Ensure CFCMonitor has write permissions to output directory
  4. Verify enabled labels are configured in ENABLED_LABELS
OBS Integration Issues:
  1. Check that OBS text sources point to correct files
  2. Ensure "Read from file" is enabled in OBS
  3. Try refreshing OBS sources
  4. Verify file update frequency matches OBS refresh rate

Performance Issues

▼
Reduce Resource Usage:
  1. Disable overlay if not needed (ENABLE_OVERLAY: false)
  2. Turn off text labels if not streaming (ENABLE_TEXT_LABELS: false)
  3. Disable Twitch bot when not streaming (ENABLE_TWITCH_BOT: false)
  4. Use smaller console font size (CONSOLE_FONT_SIZE: 8)
  5. Disable debug features (SHOW_DEBUG_TAB: false)
System Optimization:
  1. Close unnecessary background applications
  2. Set CFCMonitor to lower CPU priority
  3. Move config and backup folders to SSD if available
  4. Increase virtual memory if running low on RAM

Reset to Defaults

▼

If you're experiencing persistent issues, you can reset CFCMonitor to default settings:

⚠️ Warning: This will erase all your custom configuration. Your statistics and achievements will be preserved.
Complete Reset Process:
  1. Close CFCMonitor completely
  2. Press Windows + R and type %APPDATA%
  3. Navigate to StarCitizenLogMonitor folder
  4. Rename config.json to config_old.json
  5. Restart CFCMonitor
  6. Go through the first-time setup again
  7. Reconfigure your preferred settings
💡 Pro Tip: Before resetting, you can copy specific settings from your old config file if you want to preserve certain configurations.
