🌟 Getting Started

▼

What is CFCMonitor and what does it do?

▼

CFCMonitor is a comprehensive log monitoring application specifically designed for Star Citizen. It tracks your gameplay activities, including:

  • Kill/Death Tracking: Monitors PvP and PvE combat statistics
  • Achievement System: Unlock achievements based on your gameplay milestones
  • Player Statistics: View detailed lifetime and session statistics
  • Leaderboards: Compare your performance with other players
  • Discord Integration: Automatic notifications for significant events
  • Real-time Monitoring: Live tracking of your Star Citizen game logs

The application runs in the background while you play Star Citizen and automatically processes your game log files to provide insights into your gameplay performance.

How do I install and set up CFCMonitor for the first time?

▼

Follow these steps to get CFCMonitor up and running:

  1. Download: Get the latest version from the official source
  2. Run the Application: Launch CFCMonitor_V(#).exe
  3. First-time Setup:
    • The app will prompt you to locate your Star Citizen game log file
    • Navigate to: C:\Program Files\Roberts Space Industries\StarCitizen\LIVE\Game.log
    • Select the Game.log file
  4. Authentication: The app will verify your CFC organization membership
  5. Configuration: Choose your preferred settings in the Settings menu

Note: Make sure Star Citizen is not running during the initial setup for best results.

Why can't I find my Game.log file?

▼

The Game.log file location can vary. Try these steps:

  1. Default Location: C:\Program Files\Roberts Space Industries\StarCitizen\LIVE\Game.log
  2. Show Hidden Files: Enable "Show hidden files" in Windows Explorer (View → Hidden items)
  3. Alternative Locations:
    • C:\Users\[YourUsername]\AppData\Local\StarCitizen\Game.log
    • Check your custom Star Citizen installation directory
  4. Create the File: If missing, launch Star Citizen once to generate the log file
  5. Search Method: Use Windows search for "Game.log" in File Explorer

Tip: The log file is only created after you launch Star Citizen at least once.

🔧 Troubleshooting

▼

The application isn't detecting my kills/deaths. What should I do?

▼

If CFCMonitor isn't tracking your gameplay events, try these solutions:

  1. Check Log File Path:
    • Verify the Game.log file location is correct
    • Ensure the file exists and isn't empty
    • Check file permissions (should be readable)
  2. Game Status Verification:
    • Make sure Star Citizen is actually running
    • Check if you're logged into the game (not just launcher)
    • Verify you're in the Persistent Universe (PU) or Arena Commander
  3. Restart Sequence:
    • Close CFCMonitor completely
    • Close Star Citizen
    • Start Star Citizen first
    • Then launch CFCMonitor
  4. Use Reload Function:
    • Go to File → Reload Program
    • This refreshes the log monitoring without restarting
  5. Check Debug Log:
    • Enable debug logging in Settings
    • Look for error messages in the Feed tab
    • Check the debug.txt file in the config folder

I'm getting a "Database not available" error. How do I fix this?

▼

Database connectivity issues can prevent proper functionality:

  1. Check Internet Connection:
    • Ensure you have a stable internet connection
    • Test accessing other websites
    • Check if your firewall is blocking the application
  2. Firewall/Antivirus:
    • Add CFCMonitor to your firewall exceptions
    • Temporarily disable antivirus to test
    • Check if the app is being quarantined
  3. Restart Application:
    • Close and restart CFCMonitor
    • Wait 30-60 seconds for database connection to establish
    • Check if Player Stats tab loads properly
  4. Server Status:
    • The database servers might be temporarily down
    • Check Discord for announcements about server maintenance
    • Try again later if the issue persists
  5. Contact Support:
    • Use Help → Submit Bug Report if the issue continues
    • Include error details and your system information

The application won't start or crashes immediately. What's wrong?

▼

Startup issues can be caused by several factors:

  1. Multiple Instances:
    • Check if CFCMonitor is already running (system tray or Task Manager)
    • Close all instances and try starting again
    • Look for app.lock file in config folder and delete it
  2. Corrupted Configuration:
    • Navigate to: C:\Users\[YourUsername]\AppData\Local\CFCMonitor\
    • Rename or delete the config.json file
    • Restart the application (will recreate default settings)
  3. Missing Dependencies:
    • Ensure you have the latest Visual C++ Redistributables installed
    • Try running as administrator
    • Check Windows Event Viewer for specific error messages
  4. Antivirus Interference:
    • Add the application folder to antivirus exclusions
    • Temporarily disable real-time protection to test
    • Check quarantine for blocked files
  5. System Compatibility:
    • Verify Windows 10/11 compatibility
    • Try running in compatibility mode for Windows 8/7
    • Check if .NET Framework is up to date

My statistics aren't updating or are showing incorrect values. How do I fix this?

▼

Statistics synchronization issues can occur. Try these solutions:

  1. Manual Refresh:
    • Switch between tabs to force a refresh
    • Use File → Reload Program
    • Wait a few minutes for database synchronization
  2. Cache Issues:
    • Close and restart the application
    • Clear application cache by deleting temp files
    • Check if debug logging shows any errors
  3. Database Sync Delay:
    • Statistics may take 2-5 minutes to update in database
    • Local session stats update immediately
    • Lifetime stats depend on database connection
  4. Verify Event Detection:
    • Check if events appear in the Feed tab
    • Ensure kills/deaths are being detected correctly
    • Verify PvP vs PvE classification is correct
  5. Player Handle Issues:
    • Ensure your player handle is detected correctly
    • Check if character login events appear in the feed
    • Verify organization membership authentication

Discord notifications aren't working. How do I set them up?

▼

Discord integration requires proper webhook configuration:

  1. Webhook Setup (Admin Only):
    • Discord webhook URLs are pre-configured by administrators
    • Individual users cannot modify webhook settings
    • Contact your organization admins if notifications aren't working
  2. User-Level Troubleshooting:
    • Ensure you're authenticated with the correct organization
    • Check if your player handle is properly detected
    • Verify events are being detected in the Feed tab
  3. Network Issues:
    • Check internet connectivity
    • Verify firewall isn't blocking Discord webhooks
    • Test with different network if possible
  4. Event Filtering:
    • Only significant events trigger Discord notifications
    • PvE kills may not always generate notifications
    • Achievement unlocks should generate notifications
  5. Debug Information:
    • Enable debug logging to see webhook attempts
    • Look for Discord-related error messages
    • Use Help → Submit Bug Report for persistent issues

The application is using too much CPU/Memory. How can I optimize performance?

▼

Optimize CFCMonitor's performance with these settings:

  1. Reduce Debug Logging:
    • Disable debug logging in Settings if not needed
    • Clear the debug.txt file periodically
    • Limit console feed history
  2. Theme Optimization:
    • Use simpler themes (Dark/Light vs complex animated themes)
    • Avoid frequently switching themes
    • Reduce font size if very large
  3. Background Operation:
    • Minimize to system tray when not actively viewing
    • Close unnecessary browser tabs if using Links menu frequently
    • Restart the application periodically during long gaming sessions
  4. System Resources:
    • Close other unnecessary applications while gaming
    • Ensure adequate RAM available (8GB+ recommended)
    • Check for Windows updates and driver updates
  5. File System:
    • Place application on SSD if available
    • Ensure game log backup location has sufficient space
    • Defragment HDD if using traditional hard drive

    • View achievement progress in the Player Stats tab

Why didn't I unlock an achievement I should have earned?

▼

If an achievement didn't unlock when expected, check these common issues:

  1. Achievement Requirements:
    • Carefully review the exact achievement description
    • Some achievements have specific conditions (PvP only, specific weapons, etc.)
    • Location-based achievements require exact location matches
    • Check if the achievement distinguishes between PvP and PvE
  2. Event Detection Issues:
    • Verify the kill/death was properly detected in the Feed tab
    • Check if the event was classified correctly (PvP vs PvE)
    • Ensure your player handle was detected in the event
  3. Database Synchronization:
    • Achievement checks may take a few seconds to process
    • Database connectivity issues can delay achievement unlocks
    • Try refreshing the Player Stats tab after a few minutes
  4. Retroactive Processing:
    • Use File → Reload Program to trigger retroactive checks
    • The app performs achievement checks when starting up
    • Some achievements only trigger on new events, not historical data
  5. Troubleshooting Steps:
    • Enable debug logging to see achievement processing messages
    • Check if your statistics updated correctly
    • Restart the application to refresh achievement status
    • Submit a bug report if the issue persists

Do achievements affect my in-game Star Citizen progress?

▼

CFCMonitor achievements are completely separate from Star Citizen:

  • Third-Party System:
    • CFCMonitor achievements are independent of Star Citizen
    • They don't affect your in-game character or progress
    • No impact on aUEC, reputation, or game mechanics
    • Purely for community tracking and enjoyment
  • Data Source:
    • Achievements are based solely on log file analysis
    • No direct integration with Star Citizen servers
    • No modification of game files or memory
    • Read-only monitoring of publicly available log data
  • Community Benefits:
    • Bragging rights within the CFC community
    • Personal progress tracking and goals
    • Friendly competition with other members
    • Recognition for gameplay milestones
  • Privacy and Safety:
    • No risk of account bans or violations
    • Doesn't interfere with game performance
    • Cloud Imperium Games (CIG) independent
    • Complies with Star Citizen Terms of Service
  • Future Integration:
    • If CIG releases official APIs, integration might be possible
    • Currently no official mod support in Star Citizen
    • Will always remain optional and non-intrusive
